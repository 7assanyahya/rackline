# Security Policy

Rackline runs entirely in your browser. It has no server, no accounts, and stores projects only in your browser's local storage.

## Reporting a vulnerability

If you find a security problem (for example, a pasted project that can run code), please don't open a public issue. Instead, use GitHub's **Report a vulnerability** button on the repository's **Security** tab, or send a private message to [@7assanyahya](https://github.com/7assanyahya).

Please include steps to reproduce. You'll get a reply as soon as possible, and credit in the fix if you'd like it.
